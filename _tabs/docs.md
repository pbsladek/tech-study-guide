# Docs

This section holds the topic folders for the study guide.

Each top-level folder covers one broad technology area. Add child pages for focused topics, labs, cheat sheets, and troubleshooting notes.

## Topic Areas

| Area | Purpose |
| --- | --- |
| [Kubernetes](/docs/kubernetes/) | Cluster concepts, workloads, networking, storage, operations, and troubleshooting. |
| [DNS](/docs/dns/) | Records, resolution flow, authoritative DNS, recursive DNS, and debugging. |
| [Networking](/docs/networking/) | TCP/IP, routing, NAT, firewalls, load balancing, and packet analysis. |
| [Databases](/docs/databases/) | Database fundamentals, modeling, indexes, transactions, and operations. |
| [PostgreSQL](/docs/databases/postgres/) | PostgreSQL architecture, SQL, performance, backups, and administration. |
