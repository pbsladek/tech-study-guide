A searchable place to keep research notes, commands, diagrams, troubleshooting playbooks, and reference material.

## Main Areas

| Area | Purpose |
| --- | --- |
| [Linux](docs/linux/) | Operating system fundamentals for developers and operators: processes, memory, CPU, kernel params, GPU drivers, and troubleshooting. |
| [Kubernetes](docs/kubernetes/) | Cluster concepts, workloads, networking, storage, operations, and troubleshooting. |
| [DNS](docs/dns/) | Records, resolution flow, authoritative DNS, recursive DNS, and debugging. |
| [Networking](docs/networking/) | TCP/IP, routing, NAT, firewalls, load balancing, and packet analysis. |
| [Istio](docs/istio/) | Service mesh concepts, sidecar and ambient data planes, mTLS, traffic policy, telemetry, and troubleshooting. |
| [Ceph](docs/ceph/) | Distributed storage concepts, RADOS, pools, PGs, CRUSH, CephFS, RBD, health checks, and Rook-Ceph. |
| [Databases](docs/databases/) | Database fundamentals, modeling, indexes, transactions, and operations. |
| [PostgreSQL](docs/databases/postgres/) | PostgreSQL architecture, SQL, performance, backups, and administration. |
| [CloudNativePG](docs/databases/postgres/cloudnativepg/) | PostgreSQL operations inside Kubernetes with the CloudNativePG operator. |

## Study Page Pattern

Use this structure for new notes:

1. What problem the technology solves.
2. Core concepts and vocabulary.
3. Mental models and diagrams.
4. Hands-on commands or labs.
5. Failure modes and troubleshooting.
6. Links to deeper references.
